      使用说明

      把手机放在柜台上：对方说的变大字，你想说的点一下就播报。

      一分钟上手

      1. 选场景：点首页卡片（点餐 / 便利店 / 医院…）。长按卡片可拖动排序、隐藏或移到最前。
      2. 开始：进对话点左下 🎤，把手机放柜台；也可以直接点下面的词组。
      3. 确认：弹出「确认卡」点「都对」；听错点「不对，重问」。
      4. 收尾：点「结束」存凭证；要维权点「生成投诉材料」。

      四个常用功能

      • 递屏：整屏大字给对方看；切「您写给我」，对方可以直接手写。
      • 视频柜台：手机立在柜台上，店员入镜自动出字幕；听到“38 号到 2 号窗口”会震动弹号码；手指一下替你问；点「＋」整理常用语。
      • 紧急求助：大字“请帮我打 120”，一键拨号，或发短信给家人。
      • 医院 / 药店：自动抽出楼层、空腹、用法、金额，遇到自费会提醒。

      三个小技巧

      • 离说话人 20–30 厘米，字幕更准。
      • 太吵或对方说方言：用递屏 / 手写板。
      • 字太小点右上 A+；不想出声就只看字幕。

      常见问题

      麦克风没反应？

      需要 Chrome / Edge，并用 https 或 localhost 打开；微信内置浏览器不支持。可先点首页「看演示」。

      没有声音？

      这台设备没装中文语音包。不影响使用，屏幕就是给对方看的。

      会录音吗？

      不会。原音不保存、不上传，只留你自己生成的文字凭证。

      换手机会丢设置吗？

      会。场景、常用语、隐藏项都存在本机浏览器里；点下面「设置」可以导出再导入。
